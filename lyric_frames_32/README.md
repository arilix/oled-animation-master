# 32 Frame Script (LCD 1.3 Inch)

Dokumen ini membagi timeline menjadi 32 bagian `.md`.

Aturan:
- Total time-space lagu: 16 bagian.
- Tiap time-space dipecah jadi 2 frame: `A` lalu `B`.
- `A` dan `B` memakai lirik time-space yang sama, tetapi perkembangan bunga mawar berbeda (bertahap).
- Target layar: 240x240, kiri 45% bunga, kanan 55% lirik.

Urutan file:
- `01_S01A.md` sampai `32_S16B.md`.
